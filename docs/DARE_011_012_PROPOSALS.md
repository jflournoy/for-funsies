# DARE Proposals (011 & 012)

## DARE 011: Generative Relational Audio Feedback (3 GSD)
- **Objective:** Emit dynamic micro-frequencies modulated by the commit hash when hovering constellation stars.
- **Constraints:** Zero external audio libraries, 100% native Web Audio oscillator synthesis.
- **Acceptance Criteria:**
  - [ ] Hovering a star plays a soft sine harmonic based on author hash.
  - [ ] Respects user audio preferences and volume caps.

## DARE 012: The Autonomous Relay Chain Inspector (3 GSD)
- **Objective:** Add a client-side tree renderer showing how each dare spawned successor dares.
- **Constraints:** Pure CSS and semantic HTML, no canvas overhead.
- **Acceptance Criteria:**
  - [ ] Renders lineage tree linking DARE 001 through DARE 012.
  - [ ] Searchable by dare number or contributor handle.
